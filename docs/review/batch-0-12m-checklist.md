## The eight dimensions / စစ်ဆေးရမည့် အချက် ရှစ်ချက်

**1. Factual accuracy / အချက်အလက် မှန်ကန်မှု** — **blocking**

- EN: Does every developmental statement in this item match the linked references? Is anything asserted that the references do not support?
- MM: ဤအကြောင်းအရာထဲက ဖွံ့ဖြိုးမှုဆိုင်ရာ အချက်အလက်တိုင်းသည် ချိတ်ဆက်ထားသော ကိုးကားချက်နှင့် ကိုက်ညီပါသလား။ ကိုးကားချက်တွင် မပါသော အချက် ထည့်ထားခြင်း ရှိပါသလား။

**2. Age appropriateness / အသက်အရွယ်နှင့် သင့်တော်မှု** — **blocking**

- EN: Is this item right for the age group it is filed under? Does it set an expectation that is too early or too late for that age?
- MM: ဤအကြောင်းအရာကို သတ်မှတ်ထားသည့် အသက်အုပ်စုအတွက် သင့်တော်ပါသလား။ စောလွန်း/နောက်ကျလွန်းသော မျှော်မှန်းချက် ပါနေပါသလား။

**3. Safety / ဘေးကင်းလုံခြုံရေး** — **blocking**

- EN: Could any home activity here harm a child (falls, choking, sleep hazard, water, burns)? Is required adult supervision stated plainly?
- MM: အိမ်တွင်း လုပ်ဆောင်ချက်များတွင် ကလေးအား ထိခိုက်စေနိုင်သည့် အချက် ရှိပါသလား (လဲကျခြင်း၊ လည်ချောင်းပိတ်ခြင်း၊ အိပ်ရာဘေးအန္တရာယ်၊ ရေဘေး၊ အပူလောင်ခြင်း)။ ကြီးကြပ်မှု လိုအပ်ကြောင်း ရှင်းလင်းစွာ ဖော်ပြထားပါသလား။

**4. Myanmar wording / မြန်မာစာ သုံးနှုန်းမှု** — **blocking**

- EN: Does the Myanmar read naturally to a parent, use the correct clinical terms, and avoid any wording that belittles the child?
- MM: မြန်မာဘာသာပြန်သည် သဘာဝကျပြီး မိဘတစ်ဦး နားလည်လွယ်ပါသလား။ ဆေးပညာဝေါဟာရများကို မှန်ကန်စွာ သုံးထားပါသလား။ ကလေးအား အထင်သေးစေသော အသုံးအနှုန်း ပါနေပါသလား။

**5. Non-diagnostic language / ရောဂါအမည်တပ်ခြင်း မပါရှိမှု** — **blocking**

- EN: Is this item free of any diagnosis, any probability or percentage estimate, and any label that frames a child as abnormal?
- MM: ဤအကြောင်းအရာသည် ရောဂါအမည် တပ်နေခြင်း၊ ရာခိုင်နှုန်း/ဖြစ်နိုင်ခြေ ခန့်မှန်းပေးခြင်း၊ "ပုံမှန်မဟုတ်သော ကလေး" ဟု တံဆိပ်ကပ်ခြင်း လုံးဝ မရှိကြောင်း သေချာပါသလား။

**6. Reference relevance / ကိုးကားချက် သက်ဆိုင်မှု** — **blocking**

- EN: Is each linked reference actually about this item, and is any needed reference missing?
- MM: ချိတ်ဆက်ထားသော ကိုးကားချက်တိုင်းသည် ဤအကြောင်းအရာနှင့် တကယ် သက်ဆိုင်ပါသလား။ လိုအပ်သော ကိုးကားချက် ကျန်နေပါသလား။

**7. Outdated evidence / ဟောင်းနွမ်းနေသော အထောက်အထား** — advisory

- EN: Has any linked reference been superseded by a newer edition, and is it still appropriate to rely on the ones flagged as outdated?
- MM: ချိတ်ဆက်ထားသော ကိုးကားချက်များတွင် ဗားရှင်းအသစ် ထွက်ပြီးသား ရှိပါသလား။ ဟောင်းနေသည်ဟု အမှတ်အသားပြုထားသည့် ကိုးကားချက်ကို ဆက်သုံးရန် သင့်တော်ပါသလား။

**8. Referral guidance / ဆရာဝန်ထံ ညွှန်းပို့ရန် လမ်းညွှန်** — **blocking**

- EN: Does the item tell a parent clearly when to see a health worker, and is the guidance for urgent signs correct?
- MM: မိဘတစ်ဦး ကျန်းမာရေးဝန်ထမ်းထံ ဘယ်အချိန် သွားပြရမည်ကို ရှင်းလင်းစွာ ဖော်ပြထားပါသလား။ အရေးပေါ် လက္ခဏာများအတွက် လမ်းညွှန်ချက် မှန်ကန်ပါသလား။

A **blocking** dimension that fails means the item does not go to parents. An **advisory** dimension
that fails is recorded and scheduled, not treated as a defect — an old reference is a prompt to look
for a newer edition, not proof the content is wrong.
