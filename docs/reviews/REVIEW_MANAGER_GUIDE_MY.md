# သုံးသပ်မှုမန်နေဂျာ အသုံးပြုနည်း

## ဖိတ်ကြားခြင်း

ဖိတ်ကြားမည့်သူ၏ အမည်၊ အီးမေးလ်၊ သုံးသပ်သူအမျိုးအစား၊ အဖွဲ့အစည်း/အရည်အချင်း၊ လုပ်ဆောင်ရမည့်နယ်ပယ်၊ အသက်အုပ်စု၊ အကြောင်းအရာအမျိုးအစားနှင့် ဖိတ်ကြားချက်သက်တမ်းကို စစ်ဆေးပါ။ အီးမေးလ်မှားပါက ဖိတ်ကြားချက်ကို ပယ်ဖျက်ပြီး အသစ်ဖန်တီးပါ။

## တာဝန်ပေးခြင်း

- သုံးသပ်သူ၏ အခန်းကဏ္ဍနှင့် ကိုက်ညီသော ကဏ္ဍကိုသာ တာဝန်ပေးပါ။
- အကြောင်းအရာမူကွဲ၊ သုံးသပ်မှုအကြိမ်၊ ဦးစားပေးအဆင့်နှင့် သတ်မှတ်ရက်ကို ထည့်ပါ။
- လက်ရှိစနစ်တွင် အကြောင်းအရာတစ်ခုစီကိုသာ တာဝန်ပေးနိုင်ပါသည်။ အသက်အုပ်စု သို့မဟုတ် အမျိုးအစားအလိုက် အစုလိုက်တာဝန်ပေးသည့် လုပ်ဆောင်ချက် မပါသေးပါ။
- တာဝန်ပြောင်းပေးခြင်း သို့မဟုတ် ပယ်ဖျက်ခြင်းတိုင်း အကြောင်းပြချက်ရေးပါ။

## တိုးတက်မှုစောင့်ကြည့်ခြင်း

စုစုပေါင်း၊ မတာဝန်ပေးရသေး၊ စစ်ဆေးဆဲ၊ ပြင်ဆင်ရန်လို၊ ပြန်စစ်ရမည့်၊ ပိတ်ဆို့နေသော၊ သတ်မှတ်ရက်ကျော်နှင့် ထုတ်ဝေရန်အသင့် အရေအတွက်များကို စောင့်ကြည့်ပါ။ သုံးသပ်သူတစ်ဦးချင်း၏ ပြီးစီးနှုန်းနှင့် နောက်ဆုံးလုပ်ဆောင်ချိန်ကိုလည်း စစ်ပါ။

## အတည်ပြုချက်ကန့်သတ်ချက်

မန်နေဂျာအခန်းကဏ္ဍတစ်ခုတည်းဖြင့် မြန်မာဘာသာ၊ ကလေးဖွံ့ဖြိုးမှု သို့မဟုတ် ဆေးဘက်ဆိုင်ရာအတည်ပြုချက် မပေးရပါ။ သက်ဆိုင်ရာ သုံးသပ်သူအခန်းကဏ္ဍကို သီးခြားခွင့်ပြုထားမှသာ သက်ဆိုင်ရာကဏ္ဍကို အတည်ပြုနိုင်ပါသည်။ လိုအပ်သည့် သုံးသပ်အဆင့်အားလုံး ပြီးစီးပြီးသော မူကွဲကိုသာ Owner သို့မဟုတ် Publisher က သီးခြားထုတ်ဝေနိုင်ပါသည်။ Owner သည် ဆေးဘက်ဆိုင်ရာအတည်ပြုချက်ကို အစားထိုးပေးနိုင်ခြင်း မရှိပါ။

## အခကြေးငွေအစီရင်ခံစာ

သုံးသပ်သူက မိမိပြီးစီးသည့်အရေအတွက်၊ တစ်ခုချင်းနှုန်းထား သို့မဟုတ် ငွေပမာဏကို မပြင်နိုင်ပါ။ ငွေပမာဏများကို Owner၊ System Admin နှင့် Review Manager တို့သာ ကြည့်နိုင်ပါသည်။

Review Manager သည် audit မှတ်တမ်းနှင့် အပြီးသတ်ဆုံးဖြတ်ချက်များအပေါ် အခြေခံ၍ ငွေစာရင်းအစုကို ပြင်ဆင်နိုင်ပြီး အငြင်းပွားမှုရှိကြောင်း မှတ်သားနိုင်ပါသည်။ ငွေပေးချေရန် အတည်ပြုခြင်းနှင့် အပြင်ဘက်မှ ငွေပေးပြီးကြောင်း မှတ်တမ်းတင်ခြင်းကို Owner သို့မဟုတ် System Admin ကသာ လုပ်နိုင်ပါသည်။

ဤစနစ်က အလိုအလျောက် ငွေလွှဲပေးခြင်း မလုပ်ပါ။ `paid` ဟု မှတ်သားခြင်းသည် အပြင်ဘက်မှ လက်ဖြင့် ငွေပေးပြီးကြောင်း မှတ်တမ်းတင်ခြင်းသာ ဖြစ်ပါသည်။

## အစီရင်ခံစာ ထုတ်ယူခြင်း

ခွင့်ပြုထားသော မန်နေဂျာသည် ပြီးစီးမှုအစီရင်ခံစာနှင့် ငွေစာရင်းအစီရင်ခံစာကို CSV ဖိုင်အဖြစ် ထုတ်ယူနိုင်ပြီး ပုံနှိပ်နိုင်ပါသည်။ ငွေပမာဏပါသောအစီရင်ခံစာကို သုံးသပ်သူ၊ Publisher သို့မဟုတ် Auditor ထံ မမျှဝေပါနှင့်။ ထုတ်ယူမှုတိုင်းကို စနစ်က မှတ်တမ်းတင်ပါသည်။

အချက်အလက်များလွန်း၍ အစီရင်ခံစာက တစ်စိတ်တစ်ပိုင်းသာ ပြနေပါက စနစ်က သတိပေးစာပြပြီး CSV ထုတ်ယူခြင်းနှင့် ပုံနှိပ်ခြင်းကို ပိတ်ထားပါမည်။ အချက်အလက်မပြည့်စုံသည့်စာရင်းကို အပြီးသတ်ငွေစာရင်းအဖြစ် မသုံးပါနှင့်။
