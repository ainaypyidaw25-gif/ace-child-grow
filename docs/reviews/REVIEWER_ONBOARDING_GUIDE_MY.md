# သုံးသပ်သူ စတင်အသုံးပြုနည်း

## အကောင့်ဝင်ခြင်း

1. မိမိထံပေးပို့ထားသော ဖိတ်ကြားလင့်ခ်ကို ဖွင့်ပါ။
2. ဖိတ်ကြားထားသည့် အီးမေးလ်ဖြင့် အကောင့်ဝင်ပါ။
3. သုံးသပ်သူဆိုင်ရာ စည်းကမ်းချက်များ၊ လျှို့ဝှက်ထားရမည့်အချက်များနှင့် မှတ်တမ်းတင်ခြင်းဆိုင်ရာ အသိပေးချက်ကို ဖတ်ပြီး လက်ခံပါ။
4. ဖိတ်ကြားချက် သက်တမ်းကုန်နေပါက မန်နေဂျာထံ ဖိတ်ကြားချက်အသစ် တောင်းပါ။

## မိမိလုပ်ရမည့်အရာများ

- “မိမိတာဝန်များ” တွင် မိမိအား တာဝန်ပေးထားသော အကြောင်းအရာများကိုသာ ကြည့်ပါ။
- ခေါင်းစဉ်၊ အသက်အရွယ်၊ အမျိုးအစား၊ သုံးသပ်ရမည့်ကဏ္ဍနှင့် သတ်မှတ်ရက်ကို အရင်စစ်ပါ။
- ပြင်ဆင်ချက်ကို မူရင်းအကြောင်းအရာပေါ် တိုက်ရိုက်မရေးဘဲ “အဆိုပြုစာသား” အဖြစ် သိမ်းပါ။
- မဖြစ်မနေစစ်ရမည့် စာရင်းကို ပြည့်စုံစွာစစ်ပြီးမှ အတည်ပြုပါ။
- “ပြင်ဆင်ရန်လိုအပ်သည်”၊ “အထောက်အထားလိုအပ်သည်”၊ “ပိတ်ဆို့နေသည်” သို့မဟုတ် “ပယ်ချသည်” ကို ရွေးလျှင် အကြောင်းပြချက်ကို ရှင်းလင်းစွာရေးပါ။

## အခန်းကဏ္ဍကန့်သတ်ချက်

- မြန်မာဘာသာစကားသုံးသပ်သူသည် ဆေးဘက်ဆိုင်ရာအတည်ပြုချက် မပေးနိုင်ပါ။
- ကလေးဖွံ့ဖြိုးမှုသုံးသပ်သူသည် ဆေးဘက်ဆိုင်ရာအတည်ပြုချက် မပေးနိုင်ပါ။
- ဆေးဘက်ဆိုင်ရာသုံးသပ်သူသည် မိမိတာဝန်ပေးထားသော အကြောင်းအရာကိုသာ စစ်ဆေးနိုင်ပါသည်။
- သုံးသပ်ပြီးခြင်းနှင့် အများပြည်သူထံ ထုတ်ဝေခြင်းသည် သီးခြားလုပ်ဆောင်ချက်များ ဖြစ်ပါသည်။
- မိဘနှင့် ကလေးတို့၏ ကိုယ်ရေးအချက်အလက်များကို သုံးသပ်သူအကောင့်မှ မကြည့်နိုင်ရပါ။

## အကူအညီလိုပါက

အကြောင်းအရာ၏အဓိပ္ပာယ် မရှင်းလင်းခြင်း၊ ကိုးကားချက်မလုံလောက်ခြင်း၊ အသက်အရွယ်မကိုက်ညီခြင်း သို့မဟုတ် ဘေးကင်းရေးစိုးရိမ်ချက်ရှိခြင်းတို့ကို “ပိတ်ဆို့နေသည်” သို့မဟုတ် “အထောက်အထားလိုအပ်သည်” ဟု မှတ်သားပြီး မန်နေဂျာထံ ရှင်းလင်းချက်တောင်းပါ။ မသေချာသည့်အရာကို အတည်မပြုပါနှင့်။
