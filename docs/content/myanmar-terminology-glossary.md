# Myanmar Terminology Glossary

Consistent Myanmar terms for ACE Child Grow. **These are AI-drafted and still
require native-Myanmar and clinical review** before being treated as final.
Translators editing content via the CMS should follow this table.

| Concept (EN) | Myanmar (use consistently) | Notes |
|---|---|---|
| Development | ဖွံ့ဖြိုးမှု | |
| Milestone | ဖွံ့ဖြိုးမှု အမှတ်တိုင် | avoid literal "မိုင်တိုင်" alone |
| Emerging skill | ပေါ်ထွက်လာနေသော ကျွမ်းကျင်မှု | |
| Concern | စိုးရိမ်စရာ | not "ပြဿနာ" (too strong) |
| Review | ပြန်လည်သုံးသပ်မှု | |
| Clinical review | ဆေးပညာဆိုင်ရာ ပြန်လည်သုံးသပ်မှု | |
| Clinical Review Required | ဆေးပညာဆိုင်ရာ ပြန်လည်သုံးသပ်မှု လိုအပ်သည် | short UI form: "သုံးသပ်ဆဲ" |
| Professional | ကျွမ်းကျင်ပညာရှင် | doctor/therapist etc. |
| Activity | လှုပ်ရှားမှု | |
| Growth | ကြီးထွားမှု | |
| Sleep | အိပ်စက်ခြင်း | |
| Hope & Understanding Center | မျှော်လင့်ခြင်းနှင့် နားလည်မှုစင်တာ | |
| Corrected age | ပြင်ဆင်အသက် | premature only |
| Chronological age | ပြက္ခဒိန်အသက် | always shown |
| Tummy time | မှောက်လျက် ကစားချိန် | NOT "ပါးစပ်လှဲ" (wrong) |
| Consent | သဘောတူညီချက် | |
| Report | အစီရင်ခံစာ | |

## Rules
- Myanmar is the primary language; English may appear only as secondary
  explanatory text.
- Never present unreviewed clinical content as approved professional advice.
- Body text ≥ 16px, line-height 1.65–1.85, font stack
  `"Noto Sans Myanmar", "Pyidaungsu", "Myanmar Text", sans-serif`.

## Still requiring native-human review
All milestone, activity, awareness, and lesson wording in `src/data/seed/content.ts`
is AI-drafted placeholder marked `clinical_review`. A native Myanmar speaker +
qualified clinical reviewer must finalize before publication.
